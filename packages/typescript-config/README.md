> Status: Active

> Audience: Platform engineers

Shared **TypeScript** configuration bases for apps and packages (`tsconfig*.json` files). Extend these from app `tsconfig.json` files rather than duplicating compiler options.

Package metadata marks the config package as **MIT**-licensed (`package.json`); app licenses may differ.
